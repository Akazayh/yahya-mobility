## 📖 Overview

YAHYA Mobility is a modern car rental frontend application designed to
provide a clean and responsive experience for browsing vehicles,
viewing vehicle details, and making rental reservations.

The project focuses on:

- Premium automotive UI
- Responsive design
- Interactive vehicle catalogue
- Vehicle details
- Reservation workflow
- Modern animations and depth effects
- Mobile-friendly experience

---

## ✨ Features

- 🚘 Vehicle catalogue
- 🔎 Vehicle search and filtering
- 📊 Vehicle sorting
- 📋 Detailed vehicle pages
- 📅 Reservation workflow
- 👤 Login and registration interfaces
- 📱 Responsive design
- 🎨 Modern automotive UI
- ✨ Smooth animations and interactions
- 🧭 Multiple rental locations
- 🌐 GitHub Pages deployment
